ZhenyaAI — это личный проект по созданию собственного искусственного интеллекта.
Проект создаётся на Python и использует собственный код для обработки текста, памяти, поиска и суммаризации.
Главная цель проекта — понять, как работает языковая модель, и постепенно создать собственного полезного ассистента.

Языковая модель получает текст, превращает его в токены и пытается предсказать следующий токен.
Токен — это число, которое обозначает слово, часть слова, символ или специальную команду.
Токенизатор нужен, чтобы компьютер мог работать с человеческим языком.
Для первой версии ZhenyaAI будет использоваться BPE-токенизация.

BPE означает Byte Pair Encoding.
Алгоритм начинает с маленьких частей текста и объединяет часто встречающиеся последовательности.
Например, части слова программирование могут превратиться в более крупные токены.
Это делает обработку текста быстрее и помогает модели видеть части слов.

ZhenyaAI должен быть честным, спокойным и полезным.
Если информации недостаточно, ассистент должен прямо сказать об этом.
Если пользователь просит объяснить код, ответ должен быть понятным и содержать практические шаги.
Если пользователь работает над игрой, ассистент может помочь с Godot, Unity, Python или идеями механик.

Евгений интересуется программированием, искусственным интеллектом и созданием игр.
Он использует Windows, Git Bash, GitHub, Python, Godot и Unity.
Он предпочитает практические инструкции и полный рабочий код.
Он хочет создавать собственные проекты и постепенно улучшать свои навыки.

Python подходит для автоматизации, веб-разработки, ботов, анализа данных и машинного обучения.
Git хранит историю изменений кода.
GitHub хранит репозитории и помогает публиковать проекты.
PyTorch помогает создавать нейронные сети и обучать их на данных.
Нейронная сеть состоит из параметров, которые изменяются во время обучения.

Transformer — архитектура для обработки последовательностей.
Механизм attention помогает модели учитывать разные части текста.
Языковая модель обучается на большом количестве текстов.
Маленькая модель имеет меньше параметров и меньше возможностей, чем большие модели.

Память ZhenyaAI будет храниться отдельно от модели.
Память может содержать полезные факты о проекте, предпочтениях и предыдущих задачах.
Поиск в интернете будет отдельным инструментом.
Суммаризатор будет выбирать важные предложения из текста.
Инструменты не заменяют языковую модель, но делают ассистента полезнее.

Хороший проект создаётся маленькими шагами.
Сначала нужно создать структуру, потом обработку данных, потом модель и обучение.
Ошибки в коде — это нормальная часть разработки.
Важно читать текст ошибки, проверять путь к файлу и запускать программу снова.
