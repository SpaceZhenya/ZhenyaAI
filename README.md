# ZhenyaAI

Мой собственный проект по созданию искусственного интеллекта.

## Цель

Создать своего AI-ассистента:
- С собственной логикой и интерфейсом
- С обучением на моих датасетах
- С локальным запуском на компьютере
- С возможностью подключить веб-сайт и Telegram-бота

## План

1. Создать маленькую языковую модель с нуля на Python и PyTorch.
2. Научиться обучать её на текстовых данных.
3. Добавить генерацию текста и сохранение весов модели.
4. Дообучить открытую базовую модель на собственном датасете.
5. Создать интерфейс ZhenyaAI.
6. Подключить память, файлы, инструменты и Telegram.

## Технологии

- Python
- PyTorch
- Transformers
- Ollama — только для локального запуска моделей
- FastAPI
- HTML, CSS, JavaScript
